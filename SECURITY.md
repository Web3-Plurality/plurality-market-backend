# Security Policy

We take the security of this project seriously and appreciate the time
researchers invest in finding and responsibly disclosing vulnerabilities.
If you believe you have found one, we want to hear from you — and we have
a private channel set up so you can tell us safely.

## How to report

Go to this repository's **Security** tab and choose **Report a
vulnerability**. This opens a private advisory that only you and the
maintainers can see, where we can discuss the issue, work on a fix
together, and credit you when it is published.

To help us act quickly, please include what you can:

- the affected component or endpoint
- steps to reproduce
- expected vs actual behaviour
- impact as you understand it

## What you can expect from us

- an acknowledgement as soon as we have seen your report
- updates as we investigate and work on a fix
- credit in the published advisory, if you would like it

We ask that you keep the details between us until a fix is released, so
users of the project stay protected while we work on it. Thank you for
helping keep Plurality and its users safe.
